About

This page is part of a project to improve my open-source geospatial analysis and visualization skills. Using data from NYC's open data hub, I decided to analyze the distribution of fire hydrants across NYC's 5 boroughs. Through working on this, I realized there are different ways to normalize the data, hence why you'll see three maps below.

Each map is a choropleth, showing a gradient of hydrant density based on a different normalizing variable: neighborhood size, building count, and total building footprint size. By clicking on a neighborhood, you can see pop-ups with more details and specific values. The legend and titles also provide insight.

You can read more about the methodology in the corresponding README in the GitHub repo, and sources are linked below.

1

Hydrants per km²

In this map, we're using the area of the neighborhood as the normalizing variable to base our hydrant density.

2

Hydrants per building

In this map, we're using the building count of the neighborhood as the normalizing variable to base our hydrant density.

3

Hydrants per km² of building area

In this map, we're using the area of the building footprint in the neighborhood as the normalizing variable to base our hydrant density.
